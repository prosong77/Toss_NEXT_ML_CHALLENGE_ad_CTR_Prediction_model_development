## 📂 Project Directory Structure

```text
my-ml-project/
├── .gitignore               # Git 추적 제외 설정 파일
├── README.md                # 프로젝트 설명서 (가장 중요)
├── environment.yml          # 아나콘다 가상환경 설정 파일
│
├── data/                    # 데이터 저장소 (.gitignore로 관리)
│   ├── raw/                 # 원본 데이터 (.gitkeep으로 폴더 구조 유지)
│   └── processed/           # 전처리 완료된 데이터
...
